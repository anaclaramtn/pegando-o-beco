# Pegando o Beco

App de navegação por GPS que roda no navegador do celular e pode ser instalado na tela inicial. Busca o destino, traça a rota e guia curva a curva com instruções por voz em português.

## Como usar

1. Abra o app no celular e permita o acesso à localização.
2. Digite o destino na busca ou segure o dedo num ponto do mapa.
3. Toque em **Ir agora**.

Para instalar: no iPhone, **Compartilhar › Adicionar à Tela de Início**; no Android, **⋮ › Instalar app**.

## Feito com
- HTML, CSS e JavaScript
- [MapLibre GL JS](https://maplibre.org/) e [OpenFreeMap](https://openfreemap.org/) para o mapa
- [OSRM](https://project-osrm.org/) para as rotas
- [Photon](https://photon.komoot.io/) para a busca de endereços
